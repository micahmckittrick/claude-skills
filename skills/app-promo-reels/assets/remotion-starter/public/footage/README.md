# Footage

Put Simulator recordings here. Reels refer to them by file name (`src: 'w4-ledger-bills.mp4'`).
Prefix files with the week so each week's footage stays together. These files are large;
keep them out of version control.

The example week expects `example-ledger.mp4` and `example-trail.mp4`. Record your own, or
point the example at any vertical recording, to try a render.
